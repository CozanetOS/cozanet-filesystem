# cozanet-filesystem

Cross-platform TypeScript filesystem library offering simple, robust helper operations for managing file entries, search indexing, organization routines, zipped backups, and directory synchronizations.

## Features
- Promise-based wrapper around `fs-extra` for easy I/O
- Glob pattern file search indexing
- Automated directory organizer and file deduplication
- Zip archiving utilities with `archiver`
- Live file system watcher with `chokidar`
